# src/poc — 订单流 06《POC 怎么用：为什么这条线像磁铁》

交付说明（安装、渲染命令、输出路径、素材位置、授权）：[`../../../outputs-poc-v1/README.md`](../../../outputs-poc-v1/README.md)。
分镜、调研与示意数据：[`../../../outputs-poc-v1/分镜与调研.md`](../../../outputs-poc-v1/分镜与调研.md)。

## 文件

| 文件 | 作用 |
|---|---|
| `script.json` | 45 句口播（字幕基准）、TTS 参数、每句之后的停顿、`numbers`（口播念到的、必须与数据一致的数字）、`nocap`（以大字出现、不烧字幕的句子） |
| `timeline.json` | 由 `scripts/poc-sync.py tts` 生成：每句、每个字的起止帧，字幕分条，总帧数。代码里不写死任何帧号或时长 |
| `events.json` | 画面动作和音效的命名时间点（哪一句 + 哪个词） |
| `cue.ts` | 读时间轴和事件；缓动函数 |
| `data.ts` | 确定性的示意行情（6 个连续交易日 + 1 个独立交易日）、成交量分布、POC、价值区、所有标注用的数字 |
| `acts.ts` | 每根 K 线何时打印、分布构建到哪、发展中的 POC 在哪（随句子） |
| `lines.ts` | 每条 POC 线的位置与亮度（母题：微光 → 点亮 → 磁力线）、盘口阶梯的状态 |
| `director.ts` | 镜头：每个镜头把一组世界坐标框进屏幕矩形；换场的推拉摇移与两次硬切 |
| `world.tsx` | 3D 舞台：清漆 K 线、量柱、玻璃分布砖、POC 光线（核心 + 辉光 + 火花）、场线粒子、筹码粒子、盘口、反射地面 |
| `tags.ts` | 终端式标签（标签 + 数字，紧贴对象，对象的颜色），以及版面检查用的对象矩形 |
| `hud.tsx` | 顶栏、三步进度、大字、标签、字幕、结尾 |
| `Film.tsx` | `PocMagnet`（成片）、`PocMagnetCover`（封面） |
| `fonts.ts` / `text.ts` / `palette.ts` | 离线字体、画面文字、配色（红涨绿跌；金色只给 POC） |

脚本（`studio/scripts/`）：`poc-sync.py`（TTS / 时间轴 / SRT / BGM / 音效 / 混音 / 检查）、`poc-data-check.mjs`（数据与口播数字核对）、`poc-layout.mjs`（逐 3 帧检查标签不压 K 线、量柱、分布砖、盘口、彼此和安全区）、`poc-stills.mjs`（按事件名抽帧）、`poc-fonts.py`（字体子集）。

## 安全区

顶栏 y 250；大字带 y 380–720（只在没有图的镜头出现）；图表框进 y 740–1990、右侧留约 250 px 给价格轴标签；字幕 y 2120 起，图和标签不低于 y 2060；左右边距 48 px。
