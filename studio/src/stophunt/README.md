# 你的止损，为什么总被精准扫掉？（v1）

竖屏 1440×2560、30 fps 的金融科普短片。Remotion + Three.js（@remotion/three）实现，K 线、止损单、订单簿、标注全部由代码生成，没有视频素材和 AI 图片；中文用 Noto Sans SC / Noto Serif SC 原生渲染。行情是固定的示意数据，画面右上角始终标注「教学示意，不构成投资建议」。

## 画面结构

整片是一个 3D 场景：K 线是有体积的方块，关键价位是玻璃层板，止损单是堆在层板外侧的小方块，镜头在场景里移动。每一句旁白只配一个主标注。

| line | 章节 | 画面 |
|---|---|---|
| L01–L02 | 开场 | 镜头贴着一颗白色方块（你的止损），拉远后露出前高上方的一整堆止损；第二句标出「流动性」 |
| L03 | 01 什么是流动性 | 镜头横移到订单簿梯子：薄档 / 厚档，大单只在厚档一次成交完 |
| L04–L05 | 02 止损单，触发就是市价单 | 前高上方的空头止损（青色，触发即买入）、前低下方的多头止损（粉色，触发即卖出）；单子变暗后再慢慢堆起来；价格冲过前高，方块依次点亮、飞进金色的大参与者卖单；成交量柱放大到约 4 倍均量 |
| L06 | 03 先看位置，再看插针 | 插针标注；原来的那堆止损以虚影重新出现 |

## 时间轴：全部由 line ID 驱动

- `script.json`：15 句口播原文（字幕基准）+ 配音提示（`[短暂停顿]`、`[笑]` 只作提示，不进字幕）。
- `timeline.json`：每句的起止帧和每个短语（两个标点之间）的起止帧，以及字幕分条。**总帧数也在这里**，代码里不写死任何帧号。
- `events.json`：画面动作的命名时间点，写法是「哪一句 + 哪个词」，例如 `fire = L05 的「被触发」`。画面（`cue.ts`）和混音脚本用同一套规则换算成帧。
- 仓库里提交的是**按字数估算的占位 timeline**。换成真实配音后跑一次 `npm run sh:sync`，动画自动跟着新时间走，不用改代码。

## 文件

- `Film.tsx`：成片 `StopHunt`、封面 `StopHuntCover`。音频优先读 `public/stophunt/mix.wav`，没有就读 `public/voiceover/vo.wav`，都没有就静音。
- `world.tsx`：3D 场景（K 线、层板、止损方块堆、订单簿、成交量、缓冲带）。
- `director.ts`：镜头关键位和各场景的出入场。
- `hud.tsx`：贴在 3D 点上的标注、章节标题、卡片、字幕。安全区：左右 60 px，标注在 y 380–1900，字幕占 y 1965 以下。
- `data.ts`：两段示意行情（A：区间 + 扫前高；B：真突破 / 流动性测试两种结果）和止损方块的位置。
- `text.ts` / `fonts.ts`：画面文字；字体按这些字从 Google Fonts 取子集（渲染时需要联网）。
- `../../scripts/stophunt-sync.py`：估算 / 对齐 timeline、生成 SRT、混音。只需要 Python 3 + numpy + scipy。
- `../../scripts/stophunt-stills.mjs`：按事件名抽帧检查，例如 `node scripts/stophunt-stills.mjs out/sh 0.5 fire+10 testTag+12 cover`。

## 本地使用（都在 `studio/` 下）

1. 放配音：`studio/public/voiceover/vo.wav`（wav，任意采样率，单声道或立体声）。这个目录已被 git 忽略，不会上传。
2. 安装：

```bash
npm install
pip install numpy scipy
```

3. 对齐 + 字幕 + 混音（换音频后只需重跑这一步）：

```bash
npm run sh:sync
```

它会改写 `src/stophunt/timeline.json`，生成 `../outputs-stophunt-v1/stop-hunt-v1.srt` 和 `public/stophunt/mix.wav`（−14 LUFS，峰值 ≤ −1.5 dBFS），并打印每句的起止时间，方便核对。

4. 渲染：

```bash
npm run sh:make
```

依次执行：类型检查 → 对齐/字幕/混音 → 复制字幕 → 渲染 MP4 → 生成封面。没有独显时用 `npm run sh:make:cpu`。

输出：

- `D:/claude视频/stop-hunt-v1.mp4`
- `D:/claude视频/stop-hunt-v1-cover.png`
- `D:/claude视频/stop-hunt-v1.srt`

## 对齐原理和注意事项

脚本先按能量找出配音里的停顿，再用动态规划把停顿和文稿里的标点一一对应（逗号、句号、问号……），每个短语得到自己的起止时间；`[笑]` 当作一段不进字幕的声音处理。用合成测试音频验证过，句子边界误差在 0.05 秒以内。

如果配音几乎不在标点处停顿，对齐会退回按字数比例分配，并打印提示。这时可以检查打印出来的每句时间，必要时在 `script.json` 里调整断句后重跑。
