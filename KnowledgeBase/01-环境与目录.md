# 01 环境与目录

## 盘符规划

| 盘 | 放什么 | 说明 |
|---|---|---|
| **C:** | 程序化工具 | FFmpeg、Python 及其库、Node.js |
| **E:** | 工程与知识 | `E:\Video` 是 Git 仓库根目录，可推到 GitHub 供多台电脑同步 |
| **D:** | 不动 | 本套环境没有向 D 盘写入任何内容 |

## C 盘：已安装的工具

| 工具 | 版本 | 位置 / 安装方式 |
|---|---|---|
| FFmpeg（full build） | 9.0.2 | `winget install Gyan.FFmpeg`，命令入口 `C:\Users\<用户>\AppData\Local\Microsoft\WinGet\Links\ffmpeg.exe`，已加入用户 PATH |
| Python | 3.12 | 系统已有 |
| numpy / scipy | 2.5 / 1.18 | `python -m pip install numpy scipy`，用于程序化配乐 |
| Node.js / npm | 22 / 10 | 系统已有 |

> 新开的终端才能读到更新后的 PATH。旧终端里可以先执行：
> `$env:Path = [Environment]::GetEnvironmentVariable('Path','User') + ';' + [Environment]::GetEnvironmentVariable('Path','Machine')`

## E 盘：目录结构

```
E:\Video\
├─ .gitignore              忽略 node_modules、out 等
├─ KnowledgeBase\          ← 本知识库
└─ studio\                 ← Remotion 工程
   ├─ package.json         依赖与脚本
   ├─ remotion.config.ts   渲染配置（GL 后端、编码、并发）
   ├─ public\              静态资源（soundtrack.wav）
   ├─ scripts\
   │  └─ soundtrack.py     程序化配乐
   ├─ out\                 渲染输出（不进 Git）
   └─ src\
      ├─ timeline.json     ★ 音画共用的时间轴（场景时长、音效触发点、飞线）
      ├─ copy.ts           所有屏幕文案（中文字体按需子集化）
      ├─ Root.tsx          合成注册：Showreel + 各场景单独预览
      ├─ Showreel.tsx      总装：TransitionSeries + HUD + 音频
      ├─ lib\              rng / fonts / gsap / points / geo / glsl / timeline
      ├─ components\       Stage（3D 画布+后期）/ ParticleMorph / Hud
      └─ scenes\           IntroLogo / GlobeScene / WaveScene / Outro
```

`node_modules` 里还有 Remotion 自动下载的 Chrome Headless Shell（`node_modules\.remotion\`），约 200MB，同样在 E 盘。

## 换一台电脑复现

```bash
git clone <你的仓库地址> E:/Video
```

```bash
winget install --id Gyan.FFmpeg -e
```

```bash
python -m pip install numpy scipy
```

```bash
cd E:/Video/studio && npm ci
```

然后 `npm run studio` 打开预览，或 `npm run render` 出片。

## 关键版本约束

- `three` 锁定在 `~0.186`。`postprocessing@6.39` 要求 `three < 0.187`，升级前先检查它的 peerDependencies。
- 所有 `remotion` / `@remotion/*` 包必须是**完全相同的版本**（目前是 4.0.539）。升级时一起升：`npx remotion upgrade`。
- `@react-three/fiber@9` 要求 React 19。

## 有 GPU 的机器

当前机器没有独显，`remotion.config.ts` 里用的是 `swangle`（SwiftShader 软件渲染），稳定但慢。有显卡的机器上改成：

```ts
Config.setChromiumOpenGlRenderer("angle");
Config.setConcurrency(4); // 按 CPU 核数调
```

渲染速度通常能快 5～20 倍。
