# 分镜与视觉系统（v3）

v3 基于 v2：口播、节奏、主要观点、配乐、音效和结论都不变。这一版只调整三样：K 线镜头、标注、信息排版。代码在 `studio/src/fakeout/`。

## 一、K 线镜头：完整图 → 聚焦框 → 推近 → 标注 → 回全景

- **一张完整的 K 线图**：80 根 K 线，包括：
  - 三段上涨和两次回调（57 根）；
  - 关键位下方的震荡区间（16 根），5000.00 是前高；
  - 突破 K 线，以及后续结局 K 线（最多 6 根）。
  
  图放在深色玻璃板上，带价格网格，全景时右侧显示价格刻度。全片所有镜头都是同一张图里的同一台摄影机。
- **每个分析段落都先给全景，停留 1.2–1.5 秒**：定义、机制、信号、应对四段都是这样。之后琥珀色半透明聚焦框和聚光灯压暗框外区域，框住目标区域，再用 0.73 秒（22 帧）平滑推近。推近时宽度按几何比例变化，中心跟随宽度移动，看起来是"推进同一张图"，不是切到另一张图。
- **推近后的大小**：目标区域约占画面宽度的 35%–50%，周围 K 线保留为上下文，不再出现单根 K 线铺满全屏的画面。
- **右上角的全景小地图**：推近后出现，画出整张图，并用与聚焦框同色的琥珀框标出当前镜头的位置，会随镜头实时移动。
- **段内换焦点**：连续摇移或推拉，全片没有硬切。比如止损单 → 卖墙 → 接受区 → 止损连锁，以及收盘 → Delta 对比 → 反抽。
- **每段结束拉回全景**：口播讲到总结句时拉回，例如"正常流动性 ≠ 操纵"、"概率 ≠ 保证"和结尾提问。

| 段落 | 全景 | 聚焦 / 推近 | 推近后的标注（每个镜头最多 2–3 个） |
|---|---|---|---|
| 钩子 0:00–0:07 | 0:04 拉回全景，"假突破"标题砸入 | 开场就是中近景（约 8 根 K 线加关键位），刺穿、崩落 | 实时报价 ▲红 / ▼绿；关键位标签 |
| 定义 0:07–0:21 | 0:06.8–0:08.2 | 框住突破区 → 推近 | 真突破、回踩、失败突破，依次一次一个 |
| 机制 0:21–0:57 | 0:21.2–0:22.7 | 框住前高和关键位 → 推近 → 摇到止损单 → 卖墙 → 接受区 → 止损连锁 | 前高；止损买单；限价卖单 → 吸收面板；接受度 ≈ 0；多头止损卖单 |
| 机制收尾 | 0:50.5 拉回全景 | — | "正常流动性 ≠ 操纵"卡片 |
| 信号 0:57–1:14 | 0:56.8–0:58.2，"三个信号"标题 | 框住收盘 → 推近 → 拉到前高与新高同框 → 推到反抽 | 收盘 4974.00；前高 Delta +620 和新高 Delta +180，外加 Delta 定义；反抽 4999.50 |
| 信号收尾 | 1:11.6 拉回全景 | — | "概率 ≠ 保证"印章 |
| 应对 1:14–1:23 | 1:14.5–1:15.8 | 框住突破区 → 推近 | 五步清单；不追第一根；失效点 5016.00 |
| 收束 1:23–1:28 | 拉回全景后缓慢升高 | — | "它，被接受了吗？" + 免责声明 |

**标注节奏**：先出圆形定位标记和引线（框位置），隔 0.23 秒出名称或数值，再隔 0.23 秒出结论。面板也按"标题 → 数值 → 结论"依次出现。

## 二、字体与可读性

| 用途 | 字体 | 字号 |
|---|---|---|
| 标题、关键结论 | 思源宋体 SemiBold（Noto Serif SC 600） | 标题 230px；结论 44–110px |
| 字幕 | 思源黑体 Medium（Noto Sans SC 500） | 56px，行距 1.3，单行（最多两行） |
| 标注标题 | 思源黑体 Bold（Noto Sans SC 700） | 40px |
| 标注说明、面板正文 | 思源黑体 Medium | 34–40px |
| 价格、Delta、数值 | IBM Plex Mono Medium | 28–120px |
| 左上角辅助信息、示意图标记、小地图标签 | 思源黑体 Medium | 28px |

- 全片两套中文字体，共三个字重：宋体 600、黑体 500、黑体 700。
- 字幕：颜色 #F5F7FA，底板为 78% 不透明的深色圆角块，不用描边字。位置固定在 1440px，避开平台底部 UI。
- 所有标注都放在 82% 不透明的深色底板上，颜色只用在左右的色条、引线和定位圈上。红色或绿色文字不会直接压在 K 线上。
- 层级：标题大、数值突出、说明小。长句都拆短了，例如"新价位没有持续成交"、"接连触发 → 跌回区间"。

## 三、画面其他变化

- 去掉了镜面地板，换成深色玻璃图表板和价格网格，这样全景能看清整张图。光柱、浮尘、泛光、颗粒、暗角都保留。
- 体积雾的距离随镜头远近自动调整。激光绊线在全景里自动加粗，保证看得见。

后期：ACES 色调映射、泛光、胶片颗粒、暗角。3D 层默认按原生分辨率渲染；只有 CPU 时可以传入 `dpr: 0.75` 提速，文字和字幕始终是原生分辨率。渲染方法见 `README.md`。
