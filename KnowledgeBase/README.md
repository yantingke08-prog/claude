## 示例成片

`E:\Video\studio\out\showreel.mp4`：39 秒，1920×1080，30fps，四个场景：

1. **粒子 Logo 片头**：6 万粒子组成的螺旋星系沿噪声流场飞行，汇聚成 Logo，伴随冲击波闪光
2. **3D 数据地球**：基于真实海岸线数据的点阵地球，14 条大圆飞线，数据包脉冲、落点涟漪，加上 HUD 数据面板
3. **粒子波浪地形与动效排版**：5.8 万粒子地形，带冲击波涟漪，叠加 GSAP 逐字翻转标题和玻璃拟态卡片
4. **结尾**：粒子重组成 "MADE WITH CODE"，随后向镜头爆散，再收束成 Logo 落版

画面和声音全部由代码生成，没有使用任何外部素材。

## 一句话原则

> **画面必须是帧号的纯函数。** 给定帧号，渲染结果永远一样。Remotion 并行、乱序渲染不出错，靠的就是这一条。
