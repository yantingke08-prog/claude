# 真实回放（可选）

把真实回放按以下文件名放进本目录，就会自动替换对应画面里的合成 K 线：

| 文件 | 替换位置 |
|---|---|
| `breakdown.mp4` | 01 反差 · 左屏（卖方控制、价格破位） |
| `absorption-success.mp4` | 01 反差 · 右屏；04 吸收之后 · 有效路径 |
| `absorption-failure.mp4` | 04 吸收之后 · 失效路径 |

- 有文件时用 `OffthreadVideo` 播放，画面角标显示 `REAL REPLAY · 实盘回放`。
- 没有文件时自动回退到合成数据，角标显示 `SIMULATED · 教学示意`。
- 建议 H.264、竖向裁切或 9:16，播放时会铺满对应面板（`object-fit: cover`）。
- 放入或删除文件后，需要重启 Studio 或重新渲染，文件列表才会刷新。
- 只放你有权使用的素材。画面里不要露出账户、订单号或收益信息。
