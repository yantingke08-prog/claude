# 基础分镜（v5）

1080×1920 竖屏，144.33 秒，32 个镜头（平均 4.5 秒一个）。红涨绿跌；冷蓝是数据层，琥珀是警告色，金色是结论。本表由 `scripts/zhanqian-board.py` 从镜头表自动生成。

## 节奏规则（写在代码里）

- 每个镜头是一个连续镜头，只做一种主动作（推近、横移、绕行或局部框选）。不再按时长自动切开，也没有二次切入。
- 只在四种情况下硬切：进入新章节、3D 与 2D 图表互切、切到全屏结论、换到真正不同的对象。颜色闪切只留在 7 个章节起点。
- 同一对象内部的强调用**框选放大**：框外压暗约 13%，细发光框圈住目标，框内平滑放大到 1.10–1.12 倍（缓入 0.8 秒、停留、同速缓出），说明卡用引线连到框上。
- 没有黑场；结尾是订单池到足迹图的一次擦除。
- v5：每个镜头内部有 2–3 个以上信息节拍（新标注、数字变化、框选移动、跳档、成交带新增、路径延伸、对比线、仪表），盘口镜头常驻成交带 / 价格阶梯 / 差值 / 最新价，顶部是章节进度条。下表“数据层 / 标注”一栏仍按 v4 的主要元素描述。
- 所有叙述性文字都按配音念到的字定时出现，不会早于配音。
