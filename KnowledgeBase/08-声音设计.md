# 08 声音设计

脚本：`studio/scripts/soundtrack.py`（numpy + scipy，纯合成，不用任何采样素材）。

## 音画同步的核心

脚本读取的 `src/timeline.json` 和视频用的是同一份文件：

```python
def sec(scene, frame):
    return (starts[scene] + frame) / FPS   # 场景局部帧 → 全片秒数
```

场景起点的算法和 `lib/timeline.ts` 完全一致（同样扣除了转场重叠）。改了时间轴之后重新跑一次 `npm run audio`，所有音效会自动对齐到新的画面。

## 声音元素清单

| 元素 | 合成方法 | 用在哪 |
|---|---|---|
| 氛围铺底（Pad） | 5 声部失谐锯齿波叠和弦，分块时变低通（滤波状态跨块延续，不会有爆音） | 每个场景一个和弦，交叉淡化 |
| 次低音 | 低频正弦 + 缓慢 LFO | 全片 |
| 冲击（Impact） | 正弦频率从 144Hz 快速掉到 34Hz（底鼓）+ 低通噪声（爆裂声）+ 高通噪声（空气感），tanh 饱和 | 汇聚完成、标题落下、爆散 |
| 上升音（Riser） | 白噪声经过逐块上移的带通 + 指数上滑的 chirp | 汇聚前、出场前 |
| 嗖声（Whoosh） | 带通噪声 × sin³ 包络 | 每个转场中点 |
| 铃音（Bell） | FM 合成（调制比 3.5，调制指数随时间衰减） | 飞线到达（五声音阶）、卡片入场、结尾和弦 |
| Tick | 高频正弦短促衰减 + 高通噪声 | 飞线发射、卡片 |
| 节拍 | 软底鼓 + 反拍踩镲，120 BPM（30fps 下每 15 帧一拍），从标题落下那一拍开始 | 波浪场景 |
| 混响 | 合成立体声脉冲响应（低通噪声 × 指数衰减，3.2 秒），FFT 卷积 | 发送总线 |

和弦设计：D 空五度（神秘）→ B♭maj7（开阔）→ Cadd9（上扬）→ D 大三（解决）。

## 响度标准

最后用 FFmpeg 的 `loudnorm` 做 EBU R128 标准化：

```
loudnorm=I=-14:TP=-1.5:LRA=14
```

−14 LUFS 是 YouTube、抖音、B 站等平台的通行目标。不要只做峰值归一化：合成音乐的峰均比低，峰值归一化后会比平台标准响得多（本片最初是 −10.4 LUFS）。

## 想用真实音乐

把音乐文件放进 `studio/public/`，在 `Showreel.tsx` 里把 `soundtrack.wav` 换成你的文件名。然后：

1. 用 DAW 或 `ffmpeg -af ebur128` 找到鼓点、重拍的时间
2. 换算成帧（秒 × 30），写进 `timeline.json` 的 `cues`
3. 画面就会跟着音乐的重拍走

注意音乐版权：商用音乐需要授权。
