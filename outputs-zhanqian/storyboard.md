# 基础分镜（v6）

1080×1920 竖屏，172.43 秒，32 个镜头（平均 5.4 秒一个）。红涨绿跌；冷蓝是数据层，琥珀是警告色，金色是结论。本表由 `scripts/zhanqian-board.py` 从镜头表自动生成。

## 节奏规则（写在代码里，由 `npm run zq:layout` 检查）

- 每句话一个视觉重点：同一时刻最多 1 个主标注（说明卡 / 结论字 / 结果胶囊）+ 1 层辅助数据。
- 分类讲解：先总览（三种订单、四类参与者），再点亮当前类别，再给证据，最后落结论。
- 每个镜头只做一个主要动作：镜头运动约 18 帧内停稳，之后才出标注。
- 标注在旁白关键词前 0–8 帧开始出现；完全可见后至少停留 24 帧（说明卡 36 帧）；切点距上一句结束至少 15 帧（实际 18 帧）。时间不够时延长镜头：句间停顿加长，切点落在句子里的地方插入停顿，字词不变。
- 订单墙镜头每次换构图（见“构图”一栏），相邻两个订单墙镜头不重复。
- 强调用框选放大（框外压暗约 13%，框内 1.10–1.12 倍）；颜色闪切和 whoosh / thud 只在章节起点和两个大转折，数据出现只有轻 tick，普通切点无声。
