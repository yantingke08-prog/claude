# 放量不涨，先别追：低位看换手，高位防出货（v3）

竖屏 1440×2560、30 fps、约 76 秒的量价科普短片。Remotion + Three.js（@remotion/three）：K 线、成交量、关键价位全部由代码生成，没有视频素材和 AI 图片；中文用 Noto Sans SC / Noto Serif SC 原生渲染。行情是固定的示意数据，右上角始终标注「教学示意，不构成投资建议」，结尾单独一屏再说一次。

v3 在 v2 基础上改了三点（手机端观看）：

- **大字居中**：问题、倒计时、答案、位置 / 总结标题、交易逻辑卡、结尾，都放在各自空白区域的正中（`hud.tsx` 的 `Centered`），不再贴着上沿；仍然只在标注带里，不压图。
- **倒计时居中**：问题、圆环、「给你5秒决定」排成一列居中。
- **图更亮、有焦点**：曝光、灯光、K 线和量柱的亮度都提高，答案出现时其他 K 线只轻微压暗；当前讲到的那根 K 线背后有一团柔和的金色光晕；A / B 并排时图更大，总结时图上移、下方卡片字号加大。

和 v1 的区别：**结论先行**。倒计时结束立刻给出明确答案「先别追」和总论点「低位看换手，高位防出货」，后面只解释原因，没有「条件不够 / 无法判断」，也没有先引导选 A 再翻成 B 的反转。

配音：edge-tts（zh-CN-YunyangNeural）在你自己的机器上生成，逐字时间直接取自 TTS 的词边界。口播原文在 `script.json`。

## 版面规则：字和图分开

- 每个镜头先「框」图（`director.ts` 的 `frame()` 把一张图连同成交量放进屏幕上指定的矩形），剩下的上方 / 下方 / 侧面空白就是标注带（`bands.ts`）。
- 所有文字、卡片、勾叉都只放在标注带里；指向哪根 K 线只靠水平对齐 + 标注带边缘的一个小箭头，不画压在 K 线上的框和箭头。图上只有贴在 K 线旁边的 3D 标记（关键价位线、涨幅括号、区域）。
- `npm run vnr3:layout` 用真实相机把每张图的 K 线 + 成交量范围投影到屏幕，检查没有任何标注带碰到图，也没有图落进字幕区。
- 同一句只有一个主标注；同时最多两张卡片；标注在说到对应的词时才出现；手机安全区左右 48 px；字幕在 y 1962 以下；没有黑场转场，没有叠加的 whoosh。配色只有石墨黑、暖白、金、红（涨）、绿（跌）。

## 时间轴：全部由 line ID 驱动

- `script.json`：16 句口播原文（字幕基准）、TTS 参数、每句之后的停顿（L02 后 5.5 秒给倒计时）。
- `timeline.json`：每句、每个字的起止帧，字幕分条，总帧数也在这里。代码里不写死帧号或时长。
- `events.json`：画面动作的命名时间点，写法是「哪一句 + 哪个词」；倒计时的五秒是「L02 结束后 +8/+38/+68/+98/+128 帧」，答案在 +158 帧落下。
- 仓库里提交的 timeline 就是 edge-tts 生成的真实时间（约 76 秒）。在你的机器上重跑 `npm run vnr3:sync` 会重新生成配音和 timeline，画面、字幕、总时长自动跟着走。

## 文件

- `Film.tsx`：成片 `VolNoRise3`、封面 `VolNoRise3Cover`。音频读 `public/volnorise3/mix.wav`，没有就读 `vo.wav`，都没有就静音。
- `world.tsx`：3D 舞台。`acts.ts`：每根 K 线什么时候打印。`director.ts`：镜头（按矩形取景）和布景出入场。`bands.ts`：标注带。`hud.tsx`：倒计时、答案、标注、卡片、字幕。`data.ts`：示意行情和舞台布局。`text.ts` / `fonts.ts`：画面文字和字体子集（渲染时需要联网取 Google Fonts）。
- `../../scripts/volnorise3-sync.py`：TTS / 对齐、SRT、混音、事件检查。`../../scripts/volnorise3-layout.mjs`：版面检查。`../../scripts/volnorise3-stills.mjs`：按事件名抽帧，例如 `node scripts/volnorise3-stills.mjs out/vnr3 0.5 cd2 punch+20 cover`。

## 本地使用（都在 `studio/` 下）

```bash
npm install
pip install numpy scipy edge-tts
npm run vnr3:make
```

`vnr3:make` 依次执行：类型检查 → TTS 配音 + timeline + 字幕 + 混音（`vnr3:sync`）→ 复制字幕 → 渲染 MP4 → 生成封面。没有独显时用 `npm run vnr3:make:cpu`。

输出：

- `D:/claude视频/vol-no-rise-v3.mp4`
- `D:/claude视频/vol-no-rise-v3-cover.png`
- `D:/claude视频/vol-no-rise-v3.srt`

单独的步骤：`npm run vnr3:tts`、`npm run vnr3:srt`（字幕到 `../outputs-volnorise-v3/vol-no-rise-v3.srt`）、`npm run vnr3:mix`（−14 LUFS，峰值 ≤ −1.5 dBFS）、`npm run vnr3:check`（事件落在哪个词上 + 倒计时静音 ≥ 5.3 秒 + 版面检查）、`npm run vnr3:stills`。

## 换成自己录的配音

edge-tts 不是正式的商用 TTS 授权；商用发布前建议换成授权配音。自己录：照着 `script.json` 念，「给你五秒决定」之后停 5.5 秒以上，存成 `public/volnorise3/vo.wav`，然后 `npm run vnr3:sync:local`（`pip install faster-whisper pypinyin`），再 `npm run vnr3:prep && npm run vnr3:render && npm run vnr3:cover`。
