# 口播文案：一买就追高，不是手慢，是没分清主动和被动

- 时长目标：约 90–100 秒（按每秒 5.5 字左右的快语速；以真实配音为准，画面会自动跟随）
- 字幕和画面都以 `script.json` 里的原文为准。**改文案时请同时改 `script.json`**；如果改动了 `events.json` 里引用的关键词（例如「吃掉」「推涨」「一定不破」），那一条事件也要一起改，否则 `npm run ap:sync` 会报错提示。
- 语气：口语、快、干脆。不制造焦虑，不说"主力"，不承诺结果。

## 讲清楚的六件事（对照）

1. 主动买 = 市价单 / 止损单直接吃卖盘，跨过价差，拿走流动性，容易推涨；被动买 = 下方挂限价单，提供流动性，价格更好但不保证成交。（L02–L04）
2. 主动卖砸向买盘推动下跌；被动卖在上方挂限价卖单，等主动买来成交。关键是有没有主动跨价、推动价格。（L05–L06）
3. 追高：看到大阳线 / 突破 / 放量才进，主要推动可能已完成；主动买衰竭、Delta 不随价格创新高、大单主动买推不动 → 上方可能有被动卖盘吸收，追进去是在给别人提供退出流动性。（L07–L09）
4. 三件事：主动成交方向（持续？Delta 扩张？）、价格响应（推进了吗？）、位置和后续（突破初期 / 回踩确认，还是连续加速 / 远离结构）；主动买强 ≠ 哪都能追，被动挂单多 ≠ 一定不破。（L10–L14）
5. 吸收：两边各一次，吸收之后看价格往哪走，不能看到大单就下结论。（L15–L16）
6. 交易逻辑：不因阳线追高、不因大单盲跟，先分清拿走还是提供流动性，再看响应、跟随、承接。（L17）
