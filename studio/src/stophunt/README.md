# 你的止损，为什么总被精准扫掉？（v2）

竖屏 1440×2560、30 fps。Remotion + Three.js（@remotion/three）实现，K 线、止损单、订单簿和标注全部由代码生成；中文用原生字体渲染。行情是示意数据，右上角始终标注「教学示意，不构成投资建议」。口播文稿沿用 v1（`script.json`），没有改动。

## v2 改了什么

**时间轴：逐字对齐，画面不抢拍**
- 不再按标点猜停顿。`npm run sh:sync` 在本地用 faster-whisper 识别 `vo.wav` 的逐词时间，再把识别结果逐字对齐到文稿：同字、或（装了 pypinyin 时）同音都算匹配，漏识别的字按前后字插值。每个字都有自己的开始/结束帧。
- 也可以用其他工具导出的词级时间：`python scripts/stophunt-sync.py all --words words.json`（格式 `[{"word","start","end"}]`）。
- 所有画面动作都写在 `events.json` 里，形式是「哪一句的哪个词」，动作从这个词开口的那一帧开始，偏移只允许 ≥ 0；换场用 `after`，即上一句说完以后再切。代码里没有任何帧号或秒数。
- 字幕按完整句或完整语义段切分，最多两行；每条至少约 1.3 秒，最后一个字说完后再停 0.3 秒，不会提前切走。

**视觉**
- 真 3D K 线：倒角圆角实体、清漆高光、实时光照、软阴影，下方是有反射的地面，带雾、光柱和景深。红涨绿跌。
- 只用五类颜色：深黑蓝底、暖白文字、金色关键价位、红色（上涨 / 买方止损）、绿色（下跌 / 卖方止损）。
- 止损改成少量大块的「订单砖」：前高上方红色、前低下方绿色，各 3 层。价格扫过时逐层、从 K 线向外依次点亮，每块收成一颗光点流进 K 线，汇成一个成交脉冲落到地面的成交量柱上，最后被暖白色的大资金挂单吸收。
- 一个镜头只讲一个机制；推近用来解释，横移用来比较，拉远用来总结。
- 每段只有一个主信息（顶部一行），同一时间最多一个标注。

**结构和节奏**
- 前 8 句，每个概念至少两次有信息的变化：你的止损 → 被扫一下 → 周围落下一整堆 → 整堆变成「流动性」；订单簿厚度变化 → 大单一次成交；前高止损堆 → 一块变成买入箭头；前低止损堆 → 一块变成卖出箭头；变暗（看不见）→ 逐层堆起；扫价 → 逐层点亮 → 成交脉冲 → 对手盘吸收；插针 → 关键位 → 原来那堆止损的虚影；三条关键位 → 弹幕 → 光柱 → 三处一起堆满。
- 「止损怎么放」分成两个场景，用一次横移区分：左边是贴脸止损，被一次试探扫掉；右边是同一段行情，止损放在结构高点之外加缓冲，同样的试探没碰到它。缓冲随「波动小 / 波动大」变化。
- 结尾收拢：K 线淡出，只留关键位、止损堆和你的止损，然后是互动提问和下集预告。

## 文件

- `Film.tsx`：成片 `StopHunt` 和封面 `StopHuntCover`（阴影、景深、泛光、暗角都在这里）。音频优先读 `public/stophunt/mix.wav`，没有就读 `public/voiceover/vo.wav`，两个都没有就静音。
- `world.tsx`：3D 舞台。`director.ts`：镜头和各场景的出入场。`hud.tsx`：标题、标注、字幕。
- `data.ts`：示意行情、三个舞台的位置、订单砖。`cue.ts`：逐字时间读取和事件换算。`events.json`：画面动作对应的词。
- `../../scripts/stophunt-sync.py`：估算 / 对齐 / 字幕 / 混音。`../../scripts/stophunt-stills.mjs`：按事件名抽帧，例如 `node scripts/stophunt-stills.mjs out/sh 0.5 fire+20 badHit+16 cover`。

仓库里提交的 `timeline.json` 是按字数估算的占位版，只用来预览。真实时间以本地 `sh:sync` 的结果为准。

## 本地使用（都在 `studio/` 下运行）

1. 把配音放到 `studio/public/voiceover/vo.wav`。这个目录已被 git 忽略，不会上传。
2. 安装依赖。faster-whisper 第一次运行会下载模型，默认用 `small`；要更准可以设环境变量 `SH_WHISPER_MODEL=medium`。

```bash
npm install
npm run sh:deps
```

3. 生成逐字时间轴、字幕和混音（每次换配音后重跑这一步）：

```bash
npm run sh:sync
```

脚本会打印「matched N/M 个字」和每句的起止时间。匹配率低于 70% 时会给出提示，通常是配音和文稿不一致，或者需要换更大的模型。

4. 渲染：

```bash
npm run sh:make
```

没有独显时用 `npm run sh:make:cpu`。

输出：`D:/claude视频/stop-hunt-v4.mp4`、`stop-hunt-v4-cover.png`、`stop-hunt-v4.srt`。渲染时需要联网，因为字体子集从 Google Fonts 获取。
