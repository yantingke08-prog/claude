# 13 景深分层与统一世界

参考片：《看懂 MACD 背离》（4 分 14 秒，B 站）。拿它和我们的《交易正期望》对比之后，总结出这一套规则。

## 参考片为什么"是一整幅画"

| 维度 | 参考片 | 我们的上一版 |
|---|---|---|
| 世界 | 全片同一个夜景：星空、多层山脊、地平线上一个暖色光源 | 每章各漂一个物体在黑色虚空里 |
| 数据和环境的关系 | 数据**属于**这个世界：MACD 零轴就是地平线，柱子从地平线升起，价格线是山路，还有人在爬 | 数据和背景互不相干 |
| 光 | 一个光源统一照亮所有层次，曲线逆光发亮 | 没有光源，各处自发光 |
| 远、中、近 | 远景是星空和最远的山（最暗、最朦胧），中景是近处山脊和地平线光，近景是金色曲线、标注和人物 | 只有"背景粒子 + 前景物体"两层，而且亮度相当 |
| 颜色 | 几乎只有一个暖金色，加上数据本身的红绿 | 青、品红、琥珀、紫、绿、红六种强调色 |
| 文字 | 标注少而精 | 玻璃卡片多 |
| 镜头 | 以横移、缓推为主，像在同一片风景里走 | 自由飞行，但周围没有参照物 |

## 我们的做法：`three/World.tsx`

每一章的 3D 场景里都放同一个 `World`，所以全片在同一个地方发生：

```tsx
<World center={[10, 0, -4]} groundY={-1.4} sun={[0.5, -1]} time={t} />
```

| 层次 | 内容 | 规则 |
|---|---|---|
| 远景 | 天穹（高处深蓝，地平线一带暖色光）、星星、山后的太阳光晕 | 亮度最低，只负责氛围 |
| 中景 | 四圈山脊，越远越朦胧（大气透视）；朝太阳的一面有细细的轮廓光；深色地面上有太阳的长倒影和逐渐消失的网格 | 只是剪影，不能抢眼 |
| 近景 | 数据本身：曲线、粒子、柱子 | 全片最亮，唯一能触发明显辉光的东西 |

参数怎么定：

- `groundY`：放在数据最低点之下（第三关是 −9，托盘是 −2.2，抛硬币是 −0.6）
- `sun`：放在这一章主要镜头视线的**后方**，让数据逆光，和参考片一样
- `scale`：数据块约 20 宽时用 1；托盘这类小场景用 0.6

2D 画面（标题、公式、清单）后面的 `Ambient` 也换成了同一个 World，低机位缓慢推向地平线，所以章节之间不会掉回虚空。

## 主体与氛围拉开层次（第三关 2:11 的问题）

问题：红色"亏掉九成"平面、红色深渊和成片的轨迹，和中位数曲线亮度相近，背景抢了主体。

修复：

1. **参考面只用线，不用面**：×1 是白线，"亏掉九成"是红色虚线，去掉填充平面和深渊墙
2. **已经亏光的轨迹变成暗红余烬**，透明度降到原来的 1/4：它们只是证据，不是主角
3. **注意力调度**：讲 2% 组时 40% 组压暗到 25%，讲 40% 组时反过来
4. **主角曲线加粗加亮**：中位数线宽 6px，金白 / 冷白两色

通用规则：**环境亮度一律低于泛光阈值**，能明显发光的只有数据。

## 统一色板

| 用途 | 颜色 |
|---|---|
| 全片强调色、B、2% 组、期望值 | 金 `#f2c46d` |
| 第二数据色：A、40% 组、中位数 | 钢蓝 `#86b7dc` |
| 盈 / 亏 | 绿 `#3ff2a4` / 红 `#ff4d6d`，只用于数据 |
| 环境 | 夜蓝天、暖金地平线光 `#c8873a`、近黑山脊 |

玻璃卡片也改成暖中性色、更透明、边框更细，减少存在感。

## 远景的备选：不照搬参考片的山

山脊是参考片的做法，我们做了三套自己的、带科技感的远景，用 `World` 的 `far` 属性切换，全片统一由 `three/World.tsx` 里的 `FAR_FIELD` 一处决定（**已选定 `lattice`**）：

| 选项 | 远景 | 和主题的关系 |
|---|---|---|
| `skyline` | 地平线上一圈城市，楼高是一条首尾相接的价格走势，楼顶是K线实体、天线是影线，窗户零星亮灭，天线尖端闪烁 | 交易者的世界本身就是K线 |
| `lattice` | 点阵地形，每座山都是一条正态分布曲线，缓慢呼吸，雷达扫过时点亮 | 大数法则、分布 |
| `orbit` | 线框行星从地平线升起，挡住光源形成日冕，数据点组成的星环绕它运行 | 宏大、宇宙、科技 |

对比片段：Remotion 里的 `Exp-far-fields`（4 × 6 秒，同一镜头和数据，依次是现版山脊和三个选项）。

实现要点：远处的点只有 2–4 像素宽，柔光粒子（SOFT_POINT_FRAG）在这么小时几乎看不见，所以远景点改用实心圆点 `DOT_FRAG`。

## 盈亏柱的材质：能量玻璃（`three/Energy.ts`）

纯色加光照阴影的立方体像塑料，和全片自发光的氛围不搭。现在的柱子：

- 边线是柱子本色的霓虹光（不用白色），带较宽的光晕，只有线芯一丝发白
- 柱身半透明，越靠近柱尖越亮；柱尖端面整面泛光
- 光带从托盘往柱尖流动，柱身里偶尔闪过星点
- 叠加发光加深度预处理：一整块柱子只亮最外层表面，不会叠成一片白

## 开场封面（`Cover.tsx`，场景 `cover`，100 帧）

先给结论再进正片：左边是金属字标题「胜率陷阱」和冲突句，右边是开场那两条真实资金曲线的定格海报。节奏和音效都写在 script.json 的 cues 里：

| 帧 | 画面 | 音效 |
|---|---|---|
| 12 | 标题从模糊放大猛地落下，随后扫光 | slam：短吸气 + 重击 |
| 16–40 | 两条曲线快速画出 | riser 蓄力 |
| 40–47 | 蓝线（胜率 70%）从崖边坠向零线 | drop：下坠音 |
| 47 | 触底：冲击波、红色闪光、震屏 | boom：全片最重的一击（重击 + 低频下沉 + 碎裂噪声） |
| 52 | 金线（胜率 40%）终点亮起 | ping |
| 76–100 | 推镜穿过画面，接开场 | 场景交界的 whoosh |

配乐生成需要 ffmpeg 做响度标准化。本机没有全局 ffmpeg 时，先把 Remotion 自带的加进 PATH：`node_modules/@remotion/compositor-win32-x64-msvc`。
