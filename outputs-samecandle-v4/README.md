# 同一根大阳线，为什么结局完全不同？（v4）

v4 以 v3 为基础，没有做大改。以下内容全部保留：

- 二维固定图表层；
- 3D 只用于开场；
- 章节之间硬切；
- 零镜头抖动；
- 单标签页渲染；
- 已有的事实和配音。

| 项目 | 规格 |
|---|---|
| 时长 | 87.03 秒（2611 帧，30 fps） |
| 画幅 | 1080 × 1920；原生 2K 版 1440 × 2560 |
| 配色 | 红涨绿跌 |
| 配音 | 沿用 v1/v3 的音频。只在 w3 的两句之间加了 24 帧静音（`scripts/samecandle4-split.py`），这样"三件事"可以单独成一页，换页前旁白结束已满 18 帧，配音没有重录 |

## 这一版改了什么

1. **清理遮挡**
   - 每条标注都放在所属图表区域内的固定槽位里，用引线或括号指向目标。
   - 文字框的尺寸由 `geometry.ts` 计算，渲染时也按这个尺寸画框，所以检查的就是画面上实际的框。
   - `npm run sc4:timing` 会把每个文字框和以下内容逐一做相交检测：
     - 所有 K 线（实体和影线）、成交量柱、坐标刻度；
     - 开盘线、收盘线、一半线、均量线，以及区间带、箭头、路径；
     - 章节标题、字幕条，以及其他所有文字框。
   - 结果：105,443 次检测，0 处冲突。详见 `layout-report.md`。
2. **16 秒的"三件事"单独成页**
   - 三行大卡片，每行包含编号、短标题、一个图形和一句说明：
     - 01 位置：横盘框加突破箭头；
     - 02 量能：三根高低不同的成交量柱，带均量虚线；
     - 03 承接：一半线，加上守住和跌破两条路径。
   - 原来挤在大阳线下面的"三件事"小卡已删除。
3. **画面居中**
   - 每页都以 x = 540 为基准排版，标题、字幕和结尾文字也全部居中。
   - 检查结果：所有页面的内容中心偏移不超过 20 px（规则是 ≤ 40 px），左右边距大致对称，见 `layout-report.md`。
   - 关键文字都不超过 x = 950，避开右侧按钮列（见手机预览）。
4. **"真正"和"最关键"的强调**
   - 旁白说到这两个词时（提前 4 帧开始）：
     - 画面压暗 10%（有 6 帧的渐入和渐出）；
     - 字幕里的这个词变为金色，加下划线，放大到 1.12 倍；
     - 相关区域描一道金色亮边，只闪一次：三件事页是三张卡片，承接页是主图；
     - 混音里加一记轻微的低频声。
   - 全程没有镜头震动。
5. **v3 的架构不变**
   - 中间章节使用各自独立的二维图表，换章节时直接替换图表层。
   - 标注要等图表落位后才出现。
   - 静止画面逐帧不变，详见 `motion-report.md`。

## 本地渲染（Windows，需要 Node 18+ 和网络）

```bash
git clone -b same-candle-v4 https://github.com/yantingke08-prog/claude.git
```

```bash
cd claude/studio
```

```bash
npm ci
```

2K（1440 × 2560）：

```bash
npm run sc4:make:2k
```

1080 × 1920：

```bash
npm run sc4:make
```

两条命令都会依次完成：复制 SRT、单标签页渲染、生成封面、校验成片。最后一行输出 `All checks passed.` 即为通过。

| 命令 | 作用 |
|---|---|
| `npm run sc4:timing` | 生成 `timing-report.md` 和 `layout-report.md` |
