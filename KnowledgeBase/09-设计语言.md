# 09 设计语言

## 配色（components/Hud.tsx → C）

| 名称 | 色值 | 用途 |
|---|---|---|
| bg | `#03040b` | 背景：接近黑色的深蓝，比纯黑更有空间感 |
| cyan | `#5ce8ff` | 主强调色：数据、UI 线条、科技感 |
| magenta | `#ff4fd8` | 第二强调色：能量、冲击 |
| amber | `#ffb547` | 第三强调色：警示、进行中、城市节点 |
| violet | `#7b5cff` | 氛围色：星系、背光 |
| text | `#e9f1ff` | 正文：偏冷的白 |
| dim | `rgba(200,215,255,.55)` | 次要信息 |

规则：**一个画面最多同时出现两个强调色**，第三个只能点缀。

## 字体

| 角色 | 字体 | 用法 |
|---|---|---|
| 展示（粒子文字、英文标题） | Unbounded 800 / 300 | 宽体几何字，粒子采样后依然好认 |
| 中文 | Noto Sans SC 300 / 500 / 900 | 900 做大标题，300 加宽字距做副标题 |
| 数据、HUD | JetBrains Mono 400 / 700 | 等宽，数字跳动时不会左右抖 |
| UI | Space Grotesk | 备用 |

**中文字体子集化**：`copy.ts` 收集所有屏幕文案里的汉字，再用 Google Fonts 的 `text=` 参数只下载这些字形。一次请求就够，避免了全量加载 120 个分片。新增中文文案务必写进 `copy.ts`，否则那几个字会回退成系统字体。

## 排版

- 安全边距：左右 110px，HUD 角标在 40～100px 区域
- 英文小标签：字距 3～10px，全大写，等宽字体
- 中英双语：中文大，英文小而宽，形成层级
- 大标题字距收紧（Unbounded）或放开（中文 14–18px），看字体本身的气质决定

## 动效节奏

1. **蓄力 → 释放**：重要时刻之前先安静或反向运动（相机后拉、上升音），再在重拍上爆发
2. **重拍三件套**：闪光 + Bloom 激增 + 低频冲击音，必须在同一帧
3. **信息分层入场**：小标签 → 标题擦出 → 英文 → 分隔线 → 数据项交错，层层递进，绝不同时出现
4. **出场要比入场快**：入场 0.7～1.2 秒，出场 0.4～0.6 秒加模糊
5. **一直在动**：静止画面里也保留微动（粒子呼吸、相机漂移、数据抖动、扫描线），否则观感像 PPT
6. **镜头**：推拉用 `expo.out`，加一点点 roll（0.03–0.12 弧度）就会更有电影感
