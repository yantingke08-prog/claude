# 放量不涨，先别追：低位看换手，高位防出货（v5）

竖屏 1440×2560、30 fps、约 76 秒的量价科普短片。Remotion + Three.js（@remotion/three）：K 线、成交量、关键价位全部由代码生成，没有视频素材和 AI 图片；中文用 Noto Sans SC / Noto Serif SC 原生渲染。行情是固定的示意数据，右上角始终标注「教学示意，不构成投资建议」，结尾单独一屏再说一次。

v5 在 v4 基础上按手机端反馈修改：

- **标题去标点、水平居中**：「放量不涨 / 你会追吗」「遇到放量不涨 / 你一般怎么做」「教学示意 不构成投资建议」等画面大字不再带逗号、问号，全部居中。
- **顶部小字下移**到 y 250（避开手机状态栏 / 平台顶部按钮），大字区从 y 360 开始；封面标题同样下移。
- **字幕下移**到 y 2120；画面内容（图、标签）最低到 y 2060。
- **同一画面允许多条标注**：每个镜头里的标签按口播逐条出现，并保留到这个镜头结束（为什么：收 / 卖压 / 追价；A 特写：平台 / 换手 / 缩量 / 守住 / 站上；B 特写：放量 / 放量 / 跌破→压力 / 新低；总结六条）。版面检查保证它们互不重叠、也不碰任何 K 线和量柱。
- **标注消失时，配套的图形同时消失**：每条标签对应的价位线、区域、涨幅线、缩量连线、低点抬高的点线，都直接用这条标签的透明度画（`tags.ts` 的 `markA`），一起出现、一起消失。
- **过渡画面**：交易逻辑（L14）切到俯拍的书桌，翻开的笔记本上手写「当天先别追」，然后按口播逐行写下「低位 等站稳再考虑」「高位 跌破先回避」「止损 提前设好」，钢笔跟着笔迹移动，页面下角有一个放量长上影的速写；结尾（L15–L16）切到桌上的显示器，屏幕上是开场那张图，问题写在显示器上方的墙面空白处，最后整体压暗出风险提示。两处都是直切，前后各有约 6 帧的压黑。手写字体为 Ma Shan Zheng（Google Fonts，渲染时联网获取）。
- 只交付代码和分支；成片由本机 Codex 渲染。

v4 的规则仍然有效：**交易终端原生标注**。去掉了悬浮黑底卡片、括号、长引线、圆圈端点、勾叉清单和说明句；图上只剩贴着对象的短标签和数字：

- 标签直接贴在对象旁边，距离 ≤ 16 px：K 线上沿 / 下沿、成交量柱顶部或量柱底线下方、关键价位横线的右端（像行情软件的价格轴标签）。
- 每条最多两个信息单元，例如「放量 ×2.3」「收 +0.5%」「卖压 12.98」「缩量 1.6→0.7」「守住 11.38」「跌破 15.00」「压力 15.00」「止损 11.24」。数字取自示意数据本身。
- 文字颜色继承对象：红 = 上涨 / 涨幅，绿 = 下跌 / 跌破 / 止损，金 = 关键价位和点亮的量柱，暖白 = 支撑变成的压力线、图名。没有底板，只有贴着字形的一圈暗影保证可读。
- 图上不重复字幕：「为什么先别追」「同一根放量不涨」等标题、图下的卡片和对勾全部删掉，由字幕解释；画面只保留数据、高亮、价位线和数字变化（缩量的数字从 1.6 数到 0.7，跌破后价位线由金变白）。
- 同一时刻最多一个主标签和一个次要数字（位置那一镜，B 的「高位 +56%」出现时，A 的退成灰一点的「+14%」）；图名「A 低位」「B 高位」放在各自量柱底线下的左端。
- 留下的大字只有开场（问题、倒计时、答案「先别追」、「低位 看换手 / 高位 防出货」，后者也去掉了底板）、交易逻辑的标题「当天先别追」和结尾，都在没有图的空白区域居中。交易逻辑的三条改成图上的价位：A「站稳 12.08」、B「回避 15.00」、A 下方新加的绿色止损线「止损 11.24」。
- 对比全景和总结时图居中；B 特写、总结、交易逻辑把图左移一点，给价位线右端的价格标签留出位置。
- `npm run vnr5:layout` 现在每 3 帧检查一次所有标签：不碰任何 K 线（含影线）和量柱，离对象 ≤ 16 px，不出安全区、不进字幕区，标签之间不重叠，同一时刻不超过一个主标签。

和 v1 的区别：**结论先行**。倒计时结束立刻给出明确答案「先别追」和总论点「低位看换手，高位防出货」，后面只解释原因，没有「条件不够 / 无法判断」，也没有先引导选 A 再翻成 B 的反转。

配音：edge-tts（zh-CN-YunyangNeural）在你自己的机器上生成，逐字时间直接取自 TTS 的词边界。口播原文在 `script.json`。

## 版面规则：标签贴着对象

- 每个镜头先「框」图（`director.ts` 的 `frame()` 把一张图连同成交量放进屏幕上指定的矩形）；大字只放在图外的空白区（`bands.ts`）。
- 图上的标签全部来自 `tags.ts`：每条写明锚定的对象（哪根 K 线的上沿 / 下沿、哪根量柱、哪条线的右端）、放在哪一侧、什么颜色、哪个词出现。`hud.tsx` 只负责画，`scripts/volnorise5-layout.mjs` 用同一套数据检查。
- 标签在说到对应的词时出现、保留到镜头结束，多条可以同屏；手机安全区左右 48 px，顶部小字 y 250，字幕在 y 2120 以下；没有黑场转场，没有叠加的 whoosh。配色只有石墨黑、暖白、金、红（涨）、绿（跌）。

## 时间轴：全部由 line ID 驱动

- `script.json`：16 句口播原文（字幕基准）、TTS 参数、每句之后的停顿（L02 后 5.5 秒给倒计时）。
- `timeline.json`：每句、每个字的起止帧，字幕分条，总帧数也在这里。代码里不写死帧号或时长。
- `events.json`：画面动作的命名时间点，写法是「哪一句 + 哪个词」；倒计时的五秒是「L02 结束后 +8/+38/+68/+98/+128 帧」，答案在 +158 帧落下。
- 仓库里提交的 timeline 就是 edge-tts 生成的真实时间（约 76 秒）。在你的机器上重跑 `npm run vnr5:sync` 会重新生成配音和 timeline，画面、字幕、总时长自动跟着走。

## 文件

- `Film.tsx`：成片 `VolNoRise5`、封面 `VolNoRise5Cover`。音频读 `public/volnorise5/mix.wav`，没有就读 `vo.wav`，都没有就静音。
- `world.tsx`：3D 舞台。`acts.ts`：每根 K 线什么时候打印。`director.ts`：镜头（按矩形取景）和布景出入场。`bands.ts`：标注带。`tags.ts`：图上的标签（锚点、颜色、时间）和它们配套的图形透明度。`desk.tsx`：书桌 / 笔记本 / 显示器两个过渡场景。`hud.tsx`：倒计时、答案、标签、字幕。`palette.ts`：配色。`data.ts`：示意行情和舞台布局。`text.ts` / `fonts.ts`：画面文字和字体子集（渲染时需要联网取 Google Fonts）。
- `../../scripts/volnorise5-sync.py`：TTS / 对齐、SRT、混音、事件检查。`../../scripts/volnorise5-layout.mjs`：版面检查。`../../scripts/volnorise5-stills.mjs`：按事件名抽帧，例如 `node scripts/volnorise5-stills.mjs out/vnr5 0.5 cd2 punch+20 cover`。

## 本地使用（都在 `studio/` 下）

```bash
npm install
pip install numpy scipy edge-tts
npm run vnr5:make
```

`vnr5:make` 依次执行：类型检查 → TTS 配音 + timeline + 字幕 + 混音（`vnr5:sync`）→ 复制字幕 → 渲染 MP4 → 生成封面。没有独显时用 `npm run vnr5:make:cpu`。

输出：

- `D:/claude视频/vol-no-rise-v5.mp4`
- `D:/claude视频/vol-no-rise-v5-cover.png`
- `D:/claude视频/vol-no-rise-v5.srt`

单独的步骤：`npm run vnr5:tts`、`npm run vnr5:srt`（字幕到 `../outputs-volnorise-v5/vol-no-rise-v5.srt`）、`npm run vnr5:mix`（−14 LUFS，峰值 ≤ −1.5 dBFS）、`npm run vnr5:check`（事件落在哪个词上 + 倒计时静音 ≥ 5.3 秒 + 版面检查）、`npm run vnr5:stills`。

## 换成自己录的配音

edge-tts 不是正式的商用 TTS 授权；商用发布前建议换成授权配音。自己录：照着 `script.json` 念，「给你五秒决定」之后停 5.5 秒以上，存成 `public/volnorise5/vo.wav`，然后 `npm run vnr5:sync:local`（`pip install faster-whisper pypinyin`），再 `npm run vnr5:prep && npm run vnr5:render && npm run vnr5:cover`。
