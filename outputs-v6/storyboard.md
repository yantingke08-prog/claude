# 分镜与视觉系统（v6）

v6 是在 v5 基础上按反馈做的修改，全片 148.8 秒。代码仍在 `studio/src/fakeout/`。

## v6 改了什么

| 反馈 | 改法 |
|---|---|
| 部分画面节奏太快，看不过来 | 语速放慢 4%；句间停顿加长（分叉后 1.8 秒、每种结局后 1.3 秒、其余 0.5–1.4 秒）；开场 K 线生长从 2.9 秒拉长到 3.5 秒；主图每次推拉镜头加长约 0.4 秒；A/B/C 切换时 K 线收回和重新长出都放慢；标注出场（定位圈 → 引线 → 数字 → 标题 → 说明）从约 1.1 秒放慢到约 1.5 秒。 |
| 7 秒左右三条光轨效果不好，要三幅完整 K 线图并列 | 去掉分叉光轨。拉远时这张图一分为三：上下排开三张完整 K 线图（同一价格刻度、各自的 5000 关键位），每张从同一根突破 K 长出自己的 12 根结局 K 线。琥珀色虚线“同一根突破”竖着穿过三张图；每张图有自己的边框和标签。之后 B、C 淡出，A 那张图移到中间放大，直接变成 A 的单独全屏。 |
| 文字在字幕和配音之前出现 | 新增 `Lc(句子, 词)`，按字数估算某个词在这句里的发音时刻。所有大字、标注、进度条步骤、结论都改成在旁白说到对应词时出现。“结局 C 是怎么发生的？”移到切到主图之后、和那句旁白同时出现。 |
| 95 秒、123 秒左右的纯文字画面不够醒目 | 新的 `Statement` 大字组件：画面整体压暗 + 文字区域的暗带；逐字打出（模糊 → 清晰、上浮）；关键词金色发光（如“如何应对”“被接受”“结局不同”）；最后一行下面画出一条发光横线；可带等宽小标题（HOW TO RESPOND / ONE QUESTION）。“那我们应该如何应对？”改成小号“那我们” + 132px“应该如何应对？”。结尾“下次看到突破，先问一句”放在关键位上方，“它，被接受了吗？”128px 放在关键位下方。 |
| 121 秒左右几组文字在复杂画面上出现，需要对比度 | 三行整体压暗约 40%；“区别在突破之后 →”和三条结论都换成深色实底（94%）+ 本行颜色的 2px 描边和外发光 + 文字黑色描边与彩色辉光，字号 54px，弹入出场。 |

以下是沿用的 v5 分镜（时间码以 `script.md` 为准）。

v5 在 v4 的基础上重做了开头、三种结局、应对和结尾，并统一了标注系统。机制和三个信号（结局 C 主图）沿用 v4。旁白、时间轴、字幕、配乐和音效都按新稿重新生成，全片 130.3 秒。代码在 `studio/src/fakeout/`。

删除的内容：
- “同一根突破，三种结局”标题段；
- “这三组行情，突破之前一模一样……”这句旁白；
- 三行对比页上“突破前完全一致”“同一根突破，从这里分叉”的说明框。

## 三个“地方”（同一个 3D 世界）

- **故事图**（story）：一张纵向放大的 K 线图，33 根共同历史 + 突破 K + 12 根结局。用于开头和 A/B/C 单独全屏。
- **主图**（main）：结局 C 的完整 86 根 K 线，用来讲机制和信号（同 v4）。
- **三行对比**（rows）：用于应对段和结尾高潮。

故事图 → 主图、主图 → 三行对比，各用一次约 0.9 秒的暗场过渡。开头 0–8 秒是一条连续镜头，没有任何切换。

## 二、A / B / C 单独全屏（0:08.4–0:32.9）

- 每次只出现一种结局，不再同时出现三行。
- 切换时，突破前的 33 根 K 线和突破 K **原地不动**，只有突破后的 12 根 K 线从右往左收回，再长出下一种结局。观众能直接看出“只有突破之后不同”。
- 镜头每次切换都换一个偏航角（A 0.20、B −0.14、C 0.26），并在讲解过程中缓慢推近 4%。
- 切换的声音：whoosh + 低频 thud + 各自音高的钟声（A 高、B 中、C 低）。

每屏的版式：
- **标题**在左上留白处：彩色字母块 + 思源宋体结局名 + 等宽小字 `ENDING A · ACCEPTED`。
- **价格轴**在右侧，只标本屏相关的价位。
- **成交量条带**只在 A、B 出现（讲到成交量的两种结局）。
- 最多 3 个标注，依次出现。

| 结局 | 标注 1 | 标注 2 | 标注 3 |
|---|---|---|---|
| A 直接接受 | `5009.00` 回调低点 · 站在关键位上方 | `2,400` 成交继续放大 · 有人接力 | `5040.00` 一路走高 · 高点一个比一个高 |
| B 回踩确认 | `4999.50` 回踩 5000 · 收盘没有跌破 | `1,050 → 650` 成交量缩小 · 卖压减弱（括号框住缩量的三根量柱） | `2,300` 放量再涨 · 确认成立 |
| C 失败突破 | `5016.00` 长上影 · 新高没站住 | `4978.00` 收回关键位下方 · 回到区间内 | `4950.50` 然后转跌 · 低点越来越低 |

标注都放在当前画面的空白象限：A、B 放在左上（历史 K 线上方）和右下（结局 K 线下方），C 放在右上、左下和右下。引线从圆形定位点出发，必要时先竖直走一段再转向，以免穿过 K 线。

C 屏最后接“突破只是敲门 / 被接受，才算进门”和“结局 C 是怎么发生的？”。

## 四、应对（1:34.7–1:52.6，三行对比）

- 先压暗三行，中间大字“那我们应该如何应对？”。
- 顶部五步进度条，当前步骤的文字逐步亮起。
- **不追第一根**：绿色竖带从上往下贯穿三行的突破 K；标注“✕ 不追第一根 / 先等确认”放在 A 行左上的空白处，指向竖带。
- **讲 B**：B 行高亮（放大 6%、边框、聚光），A、C 压暗。大号标注放在压暗的 A 行里，引线连到 B 的回踩（`4999.50` 顺着突破做 · 等回踩守住 · 像结局 B）；B 行上画失效点虚线 `4998.50`。
- **讲 C**：C 行高亮。大号标注放在压暗的 B 行里，引线连到 C 的反抽高点（`4998.50` 判断是假突破 · 等反抽站不上 · 像结局 C）；C 行上画失效点虚线 `5000.00`。
- **讲风险**：B 行高亮。风险卡横跨压暗的 C 行，竖线连回 B 的入场价和失效点：入场 5009.00、失效点 4998.50、风险从 0 递增到 10.50 点，最后补一句“先定失效点，再定仓位”。

## 五、结尾高潮（1:52.6–2:10）

1. “同样的突破，为什么结局不同？”；琥珀竖线标出“区别在突破之后 →”，A/B/C 的结论依次滑入。
2. **回卷**：三行的结局 K 线从右往左快速收回，回到同一根突破 K（反向 whoosh）。
3. **叠加**：A、C 两行滑向中间与 B 重合，镜头推近，画面发光一下（低频冲击 + 轻微震动）。
4. **光轨**：三条彩色光轨从突破 K 重新长出，短暂停留，然后逐点折向 5000 关键位，同时 K 线淡出、关键位变粗并延伸出画面。三个滑音收束到同一个音。
5. 最后只剩发光的关键位，下方是“它，被接受了吗？”；免责声明淡入。

## 六、标注系统（`Hud.tsx` 的 `Callout`）

- 字体：数字一律用 IBM Plex Mono 500；结论和大标注用思源宋体 600；标签用思源黑体 700/500。
- 出场顺序：圆形定位点（先放大再收紧）→ 引线生长 → 数字滑入并递增 → 标题 → 说明，每步大约 0.2–0.3 秒。
- 底板统一：深色 84% 底、圆角 12、靠引线一侧 6px 色条、柔和阴影；同一时刻的底板互不重叠。
- 底板位置由 3D 点投影得到，所以会随镜头轻微移动，不是贴死在屏幕上。
- 尺寸：标准标注是数字 46 / 标题 38 / 说明 34px；应对段的大号标注是数字 50 / 标题 52（宋体）/ 说明 38px。
- 价格递增按 0.25 的最小跳动取整。

## 七、字体与可读性（沿用 v3/v4）

- 字幕：56px，颜色 #F5F7FA，放在 78% 不透明的深色底板上，位置固定在 1440px。
- 全程右上角显示“示意图 · 模拟数据”；结尾显示“教育内容，不构成投资建议”。

## 声音

- 全部由 `scripts/fakeout-score.py` 程序合成，事件时间和画面读同一个 `src/fakeout/events.json`。
- 混音：响度 −13.9 LUFS，真峰值 −5.5 dBTP；人声出现时音乐压低约 10 dB、音效约 4 dB。
