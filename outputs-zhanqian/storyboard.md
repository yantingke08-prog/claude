# 基础分镜（战前觉醒 · 第 1 期）

1080×1920 竖屏，158.2 秒。红涨绿跌：红色 = 上涨 / 买方，绿色 = 下跌 / 卖方。全片是一个 3D 世界里的四个场景，场景之间用约 0.8 秒的暗场衔接。代码在 `studio/src/zhanqian/`。

## 本期取舍

- **讲了**：
  - 市场是持续拍卖（买卖两堵墙、价差、成交量买卖相等）；
  - 三种订单（被动 / 主动 / 止损）和价格移动的最小过程；
  - 四类参与者；
  - 从“看 K 线结果”到“问订单原因”。
- **留到下一期**：足迹图（footprint）、Delta、吸收、冰山单、成交量分布。片尾预告“下一期走进足迹图”。
- **准确性边界**：
  - 明确说“操纵确实存在，它是违规行为”，但日常大多数波动来自不同需求的碰撞；
  - 结尾提醒“挂单可以撤，订单流只能提高概率”。

## 视觉系统

- **美术**：深石墨背景，暖金色主光，冷蓝色轮廓光。材质有清漆质感的订单方块、拉丝金属棋子、从内部发光的玻璃 K 线。
- **大字**（`Statement`）：
  - 画面压暗；
  - 文字在旁白念到时才逐字打出；
  - 关键词金色发光，下面画出一条发光横线。
- **标注**（`Tag`）：定位圈 → 引线 → 深色实底牌（彩色发光描边）→ 说明逐行出现。
- **字幕**：56px，深色底板，固定在 1480px 高度。关键词（被动订单、做市商等）用金色。
- **定时规则**：所有屏幕文字都按 `Lc(句子, 词)` 定时，不会早于配音出现。
