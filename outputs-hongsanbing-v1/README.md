# 红三兵：三根阳线，不一定是机会 · v1

竖屏 1080×1920 / 30 fps / 80.4 s（2412 帧），全部为代码生成的 2D 矢量画面，没有用任何现成视频素材。配音为 edge-tts `zh-CN-YunxiNeural`，配乐和音效全部是合成的原创内容。混音为 −14.5 LUFS，真峰值 −1.4 dB。

源码：`studio/src/hongsanbing/`。合成（Composition）有 `HongSanBing`、`HongSanBing2K`、`HongSanBingCover`、`HongSanBingCover2K`。

## 渲染（本地）

```bash
cd studio
npm install
npm run hsb:make          # 字幕 → 成片 → 封面 → 校验（GPU: --gl=angle）
npm run hsb:make:cpu      # 没有 GPU 时使用（--gl=swangle）
npm run hsb:make:2k       # 1440×2560
```

输出：`D:/claude视频/hong-san-bing-v1.mp4`、`-cover.png`、`.srt`。
字体在渲染时从 Google Fonts 拉取，所以渲染机需要联网。

重新生成音频管线时，按这个顺序执行：`hsb:vo`（配音 + timeline.json）→ `hsb:audio`（配乐/音效/混音）→ `hsb:srt`。

## 制作规则

- K 线采用红涨绿跌。画面上的文字都按配音的字级时间戳出现，不会早于配音。每个画面最多同时出现 2 个标注。
- 关键内容放在 y 140–1340，字幕在 y 1392，字号 56 px，每行不超过 14 个汉字，不会剩下单独一个字的行。右侧和底部避开手机 App 的按钮区。
- 所有 K 线数据都是手工设计的示意数据（`data.ts`），不是真实行情。

## 待办 / 注意

- edge-tts 不是正式的商用 TTS 授权。商业发布前，请改用 Azure Speech 或有授权的真人配音重新配音（重新跑 `hsb:vo` 即可，时间轴会随之更新）。
