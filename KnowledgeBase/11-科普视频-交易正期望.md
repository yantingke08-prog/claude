## 做法要点

### 数字只有一个来源

`sim.ts` 的结果同时供三处使用：画面上的图表、烧录字幕里的 `{p10}` 这类占位符、导出的 SRT 和简介。改了模拟参数，三处会一起变，不可能对不上。

Node 22 可以直接运行 `.ts` 文件（类型擦除），所以导出脚本 `import` 的就是视频用的同一份 `sim.ts`。为此 `sim.ts` 内部的 import 写了 `.ts` 扩展名，`tsconfig` 也开启了 `allowImportingTsExtensions`。

### 改文案或时间只动 script.json

- 字幕：`{ "from": 场景内帧, "to": 场景内帧, "text": "…**高亮**…{占位符}…" }`
- 音效：`cues` 里的 `hit / riser / whoosh / tick / ping`
- 改完运行 `npm run exp:audio` 和 `npm run exp:publish`

画面动画的时间点写在各个场景的 tsx 文件里，和字幕的帧号是对应的。调整字幕时间时，要同时看对应的场景代码。

### 图表技术选型

| 图 | 技术 | 原因 |
|---|---|---|
| 资金曲线、面积图、公式 | SVG / HTML | 元素少，要求文字锐利 |
| 1000 条扇形线、对数扇形、直方图、连亏格 | Canvas 2D | 几十万个线段点，DOM 撑不住；用 "lighter" 叠加加自模糊做发光 |
| 背景概率云 | Three.js（全片共用一个） | 只开一个 WebGL 上下文，省渲染时间 |

### 二项分布直方图的坑

±50%/−40% 游戏中，r 把之后的资金只可能是 `1.5^k × 0.6^(r−k)` 这几种离散值。用固定宽度分箱会出现"一高一空"的锯齿。正确做法是**按正面次数 k 分箱**（见 `ErgoHistogram`）。

### 中文字体分片

这部片子用到几百个汉字，一次 `text=` 请求的 URL 太长。`lib/fonts.ts` 改成每 120 个字一个请求，并给每个 `@font-face` 注入只包含这些字的 `unicode-range`，浏览器会按字拼成同一个字体族。

## 合规

- 只讲概率原理，不提任何具体品种、平台或操作建议
- 所有图表标注"模拟数据 · SEEDED MONTE CARLO"
- 片尾有完整风险提示，字幕和简介里同样带上
- 策略 A、B 是教学用的简化模型，简介里已经写明
