# 10 踩坑记录

按"现象 → 根因 → 修复"记录。遇到新问题请继续往下补充。

---

### 1. 3D 画面全黑（只有 HTML 层可见）

- **现象**：`remotion still` 出图时，WebGL 部分全黑；去掉 `EffectComposer` 就正常。
- **根因**：`ThreeCanvas` 在 GL 上下文创建时只渲染一次，那时 `EffectComposer` 的 passes 还没挂上。出单帧时帧号不会再变化，所以不会触发第二次渲染。全片渲染时，每个浏览器标签页的第一帧也会是黑的。
- **修复**：`Stage.tsx` 里的 `PostMountRender`：挂载后（以及每次帧号变化后）用 `delayRender` 挂起截图，等一个 `requestAnimationFrame` 后再调用一次 `advance()`。

### 2. `structuredClone` 报 DataCloneError

- **现象**：`Failed to execute 'structuredClone' ... function _getProperty`
- **根因**：GSAP 会往补间目标上挂 `_gsap` 缓存对象，里面有函数和循环引用。
- **修复**：手写 `snapshot()` 递归克隆，跳过 `_gsap` 键。

### 3. npm 安装报 ERESOLVE（three 版本冲突）

- **现象**：`postprocessing` 的 peer 依赖要求 `three >= 0.168.0 < 0.187.0`，但装上的是 0.187。
- **修复**：`npm install three@0.186`，`@types/three` 同步锁定到 `~0.186`。

### 4. 粒子太小，看起来像灰尘

- **现象**：6 万个粒子只有 1px，几乎看不见。
- **根因**：`gl_PointSize` 的透视系数是按小分辨率估的。
- **修复**：1080p 下系数取 34（`uSize * 34 / -mv.z`）。

### 5. 粒子汇聚途中变成一团白雾

- **根因**：加法混合下，飞行途中又提亮又放大，6 万个点叠加后过曝。
- **修复**：飞行中改用饱和色，降低透明度，尺寸只放大 25%。

### 6. 小粒子出现红蓝重影

- **根因**：色差（ChromaticAberration）偏移 0.0012 太大，对 1～3px 的点来说非常明显。
- **修复**：降到 0.0005。

### 7. 地球点阵出现指纹状条纹

- **根因**：斐波那契点阵和屏幕像素网格形成莫尔纹。
- **修复**：每个点加 ±0.22° 的确定性抖动。

### 8. 渐变文字后面出现一个暗色矩形

- **根因**：`background-clip: text` 的元素上又加了 `filter: drop-shadow`，Chrome 会给整个盒子生成阴影层。
- **修复**：去掉 filter。需要发光就在外层套一个容器，或者用 text-shadow（文字不能是透明色）。

### 9. 中文字体加载请求过多、渲染超时

- **根因**：Noto Sans SC 每个字重有约 120 个 unicode-range 分片。
- **修复**：Google Fonts CSS2 的 `&text=` 参数只请求用到的字，详见 `lib/fonts.ts`。

### 10. 响度过大

- **根因**：峰值归一化无法控制感知响度，合成音乐峰均比低，结果达到 −10 LUFS。
- **修复**：FFmpeg `loudnorm=I=-14:TP=-1.5`。

### 11. SwiftShader 弃用警告

- **现象**：日志里出现 `Automatic fallback to software WebGL has been deprecated`。
- **说明**：只是警告，`swangle` 后端仍然正常工作。有 GPU 的机器改用 `angle`。

### 12. 安装 FFmpeg 后当前终端找不到命令

- **根因**：winget 修改的是用户 PATH，已经打开的 shell 不会刷新。
- **修复**：新开终端，或者手动刷新 `$env:Path`（见 01 文档）。

### 13. Git Bash 的 heredoc 里写中文和反引号会解析失败

- **现象**：`unexpected EOF while looking for matching`
- **修复**：写较长的源码文件时，不要用 shell heredoc，直接用编辑器或文件写入工具。
