# 05 粒子系统

组件：`components/ParticleMorph.tsx`。片头 Logo 和结尾文字都用它。

## 思路

每个粒子带两个位置，在 GPU 里插值：

- `aStart`：起始形态（螺旋星系 / 球壳）
- `position`：目标形态（从文字/Logo 采样出来的点）
- `aRand`：4 个随机数，控制延迟、大小、颜色、相位

JS 端每帧只传 `uProgress`（0→1）、`uScatter`、`uTime` 三个数，6 万个粒子的运动全部在顶点着色器里算。

## 1. 目标点：把任何 2D 图形变成点云

`lib/points.ts` → `samplePoints(draw, count)`：

1. 建一个离屏 canvas，调用 `draw(ctx)` 画出文字或 Logo（白色）
2. `getImageData` 后隔 2 像素扫描一次，收集 alpha > 140 的像素
3. 用带种子的随机数从中抽取 `count` 个点，加亚像素抖动和少量 Z 方向厚度
4. 换算成世界坐标，并以原点为中心

**必须等字体加载完再采样**，否则会用回退字体画出错误的形状。`useSampledPoints()` 已经处理好了。

想换 Logo，只要写一个新的 `Draw` 函数：canvas 2D 能画出来的形状，粒子都能拼出来。

## 2. 起始形态

```ts
// 三旋臂螺旋星系
const radius = 0.8 + Math.pow(rand(), 1.35) * 13.5;   // 指数 >1 让中心更密
const angle = arm + radius * 0.42 + gauss() * 0.35;   // radius*0.42 决定旋臂卷曲程度
y = gauss() * (0.25 + 1.2 / radius);                  // 中心更厚（核球）
```

着色器里让星系做**较差自转**：内圈转得快，外圈转得慢。

```glsl
vec3 start = rotY(aStart, uTime * 1.1 / (0.6 + r * 0.22));
```

## 3. 汇聚动画

```glsl
float delay = aRand.x * 0.42;                         // 每个粒子出发时间不同
float p = clamp((uProgress - delay) / 0.58, 0.0, 1.0);
float e = easeInOutCubic(p);
vec3 pos = mix(start, target, e);
float flight = sin(p * 3.14159);                      // 飞行中段为 1，两端为 0
pos += flight * flow * (1.6 + aRand.y * 2.2);         // 沿噪声流场偏移，到达后自动归零
```

关键在 `flight = sin(p·π)`：只有飞行途中才有扰动，所以起点和终点都是精确的，中间又很有机。

### 让画面不"糊"

最初的版本在飞行途中把颜色往白色推，结果 6 万个点叠成一团白雾。改成：

- 飞行中改用**饱和的青/品红**（`streak` 色），而不是加亮
- 飞行中透明度降到 65%，尺寸只放大 25%

经验：**加法混合下，亮度要靠"少而亮"，不能靠"多而灰"。**

## 4. 呼吸与爆散

- 到达之后每个粒子还保留 ±0.025 的正弦微动，Logo 不会显得像静止的贴图
- `uScatter`：沿"中心→粒子"方向向外炸开，同时朝镜头方向（+Z）冲，配合相机震动和闪光

## 5. 参数速查

| 参数 | 片头 | 结尾 |
|---|---|---|
| 粒子数 | 60,000 | 60,000 + Logo 30,000 |
| `size` | 1.9 | 1.7 |
| 起始形态 | galaxy | shell |
| 汇聚帧段 | 12→150 | 8→110 |

## 6. 时间轴配合

汇聚完成的那一帧 = `cues.intro.hit`。同一帧触发：

- `Impact` 组件（全屏闪白 + 冲击波环）
- Bloom 强度瞬间拉到 1.9 倍再回落
- 配乐里的低频冲击音

三者合在一起，"汇聚完成"才会有打击感。
